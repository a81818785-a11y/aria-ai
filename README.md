# ARIA AI - Android starter

This is an early Android prototype. It builds a debug APK through GitHub Actions.

## Build
1. Upload the contents of this folder to the root of your GitHub repository (keep folder paths).
2. Open the repository's Actions tab.
3. Run or wait for **Build ARIA AI APK**.
4. Open the completed run and download the `aria-ai-debug-apk` artifact.

## Important
This is a UI prototype only. It does not yet connect to a real AI service, implement accounts, store chat history, or provide voice input/output. Add a secure backend before public release. Never put an AI provider secret key in the Android app.
